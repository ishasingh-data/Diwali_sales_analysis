# Diwali_sales_analysis
### 🪔 Diwali Sales Data Analysis Project
## 📌 Overview

This project focuses on analyzing Diwali sales data to extract meaningful business insights using Python and data analysis libraries. The dataset contains customer demographics, purchasing behavior, and transaction details, which help in understanding sales trends and customer segmentation.

As a Senior Data Analyst, the goal of this project is to:

- Identify high-value customers
- Analyze purchasing patterns
- Understand regional and demographic trends
- Support data-driven decision-making for business growth

## 🛠️ Tools & Technologies Used
Python
NumPy – Numerical computations
Pandas – Data cleaning and manipulation
Matplotlib – Data visualization

## 🔍 Key Steps in Analysis
1. Data Loading
  Imported dataset using Pandas
  Inspected structure and data types
2. Data Cleaning
  Removed null values
  Dropped irrelevant columns (unnamed1)
  Corrected data types
  Handled duplicates
3. Exploratory Data Analysis (EDA)
  Gender-wise spending analysis
  Age group vs purchasing power
  State-wise and zone-wise sales distribution
  Occupation-based buying behavior
  Product category performance
4. Data Visualization
  Bar charts for category comparisons
  Histograms for distribution analysis

## 📊 Key Insights
Married women (age 26–35) are the highest spenders during Diwali
Top-performing states/zones contribute significantly to total revenue
Certain product categories dominate sales
Occupation plays a major role in purchasing power
Repeat customers contribute to higher revenue
